DATA SORTING (ORDER BY)

Data Sorting means arranging query results in specific order
Ascending order ( small to large)
Descending Order (large to small)

syn: select column1,column2
from tablename
order by [asc or desc];

SELECT * 
FROM employees
ORDER BY salary DESC; -- arrange rows in desc order by salary (highest to lowest)



SELECT * 
FROM employees
ORDER BY salary asc; -- arrange rows in asc order by salary (lowest to highest)

--Sorting by Multiple Columns

SELECT * 
FROM employees
ORDER BY department DESC ,salary ASC; 
--First sorts by department
--Then within each department → sorts by salary

--Sorting by Column Position
SELECT emp_id, first_name, salary
FROM employees
ORDER BY 3 DESC;(3 refers to the third column (salary))

--Sorting by Alias
SELECT emp_id,first_name,last_name,department,salary,salary * 12 AS annual_salary
FROM employees
ORDER BY annual_salary DESC; 

--Sorting with Where
SELECT * 
FROM employees
WHERE department = 'IT'
ORDER BY salary DESC; -- first where clause will execute and gather the dept col and then salary col will sort by highest to lowest
